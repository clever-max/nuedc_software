# 固件镜像说明

`car.hex` 是当前 `car` 工程的 Intel HEX 固件镜像，可直接交给兼容的 TI 烧录工具。其他历史测试镜像若存在，必须按其文件名和生成记录区分，不能把测试镜像当作当前主程序。

烧录后应先退出 BSL，再复位或启动应用。电机测试时架空车轮，并断开无关传感器。烧录、编译和实车运行是三个独立结果，需分别记录。

当前镜像包含 NCHD12 PA29/PA30 软件 I²C 地址探测、灰度总线 ACK 遥测，以及 Motor B 电气反相和左右编码器方向修正。串口遥测可用 `gray_bus=OK`、`gray_bus=NACK1/2/3` 区分总线状态。
