# AT8236 资料核对

## 本项目采用的事实

供应商资料位于 `../vendor/`。AT8236 是有刷直流电机 H 桥，资料给出的 PWM 范围为 0–100 kHz，推荐值为 10 kHz。输入低低为高阻滑行，输入高高为刹车；实际方向取决于电机和模块接线。

D157B 资料给出 VM 为 5.5–17 V、VREF 为 0.5–4 V，并强调不可互换。当前 PA0/PA1/PA8/PA9 映射来自本项目接线和 `car.syscfg`，不是供应商 STM32 示例。

## 不应直接套用的内容

STM32/Arduino 示例的串口引脚、PWM 引脚和编码器定时器针对其他硬件；当前实车架空验证表明 Motor B 需要在 BSP 中电气反相，才能使正命令代表两轮物理前进。当前项目使用板载 UART0 PA10/PA11，编码器使用 PA27/PA25/PB25/PB20，电机 PWM 使用 PA0/PA1/PA8/PA9。

编码器 A/B 的输出电平在供应商手册中没有被明确为 3.3 V、5 V 推挽或开漏；接入前必须单独测量并核对 MSPM0 容限。
