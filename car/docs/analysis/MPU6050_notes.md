# MPU6050 接入说明

当前路线只使用原始 MPU6050 I²C 数据，不使用串口姿态模块。

## 接线

| MPU6050 | 天猛星 MSPM0G3507 |
| --- | --- |
| SCL | PB2 / I2C1_SCL |
| SDA | PB3 / I2C1_SDA |
| INT | PB1，保留为数据就绪输入 |
| VCC/GND | 按模块电源要求供电并共地 |

AD0 悬空按地址 `0x68` 使用。固件启动后读取 `WHO_AM_I`，配置唤醒、数字低通、200 Hz 采样和 ±250°/s 量程，然后在车辆静止时采集 100 个 Z 轴角速度样本。

## 控制数据链

```text
GYRO_ZOUT_H/L -> 去零偏 -> 一阶滤波 -> 角速度积分 -> yaw
                                                    |
灰度位置误差 + 编码器速度 PID -> 电机 PWM ------+-> 弯道状态切换
```

按 B21 或发送 `RUNPID`/`RUN15` 后，状态机立即进入第一段弯道。第一段累计约 170° 的有效 yaw 变化后进入直道；直道中检测到同方向持续角速度后进入第二段弯道；第二段再次达到约 170° 后停车。

## 启动和故障判断

1. 复位后保持小车静止约 0.5 秒，让零偏校准完成。
2. 通过 UART1 调试口观察 `backend=MPU6050` 和 `gyro=OK`。
3. `gyro=ERR` 表示 `0x68` 无应答、读寄存器超时或校准读取失败，B21 和 `RUN15` 会保持停车。
4. 首次上车测试应架空车轮，先确认 yaw 随手动旋转方向变化，再接触地面测试灰度循迹。
