# MPU6050 接入说明（保留功能）

当前固件明确在 `app.c` 中不调用 MPU6050 初始化和更新接口，启动信息显示 `MPU6050 disabled`，因此本文是未来启用姿态路线时的接口记录，不是当前运行行为。

## 预留接线

| MPU6050 | MSPM0G3507 |
| --- | --- |
| SCL | PB2 / I2C1_SCL |
| SDA | PB3 / I2C1_SDA |
| INT | PB1（预留） |
| GND | GND |

驱动使用 7 位地址 `0x68`、±250 dps、约 200 Hz 采样，启动时采集 100 个静止样本作为零偏。启用前必须先核对模块电平、上拉电压和 I²C 应答，并同步修改 `app.c` 与任务状态机。

## 与当前工程的关系

- 当前启动不会因 MPU6050 缺失而失败。
- 当前 `gyro=OFF`，弯道识别和停止完全不依赖 yaw。
- 不能使用本文的弯道角度或校准步骤宣称当前固件已完成陀螺仪闭环。
