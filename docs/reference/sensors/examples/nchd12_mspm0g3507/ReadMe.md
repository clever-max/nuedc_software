# NCHD12 资料包示例说明

本目录是供应商资料包中筛选出的旧例程快照，实际内容包含软件 I²C 和 OLED 显示示例，不是当前 `car` 工程的构建入口。

- 原例程面向 Keil 和旧版 MSPM0 SDK/SysConfig。
- 原例程中的安装目录、头文件搜索路径和引脚仅供复现该快照时参考。
- 当前工程不要求安装到固定系统目录，工具路径应由本机环境或 CCS 配置提供。
- `car` 工程的灰度总线由 `car.syscfg` 定义为 PA28/PA31；不能直接复制该例程的 PA0/PA1 配置。

需要复现原始例程时，请根据本机工具安装位置调整路径，并把它视为独立参考工程。
